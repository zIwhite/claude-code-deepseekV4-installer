============================================================
    Claude Code + DeepSeek V4 一键安装包使用说明
============================================================

本安装包帮助你一键安装 Claude Code，并接入 DeepSeek 提供的
大模型 API，在 Windows 电脑上免费、低费用使用 AI 编程助手。

同时提供一键清理脚本，可彻底移除本安装包生成的所有内容，
恢复到安装前的状态。

本压缩包包含三个文件：
  - 安装ClaudeCode.bat      ← 一键安装脚本（自动装Node.js/Git/Claude Code）
  - 清理ClaudeCode.bat      ← 一键清理脚本（移除所有相关文件和环境变量）
  - README.txt              ← 本说明文件


【第一部分：一键安装】

【第一步】以管理员身份运行安装脚本

  右键点击 "安装ClaudeCode.bat" → 选择 "以管理员身份运行"。

  如果 Windows 弹出 "Windows 保护了你的电脑" 蓝色提示，
  点击 "更多信息"，然后点 "仍要运行" 即可。

  如有杀毒软件拦截，请点 "允许" 或 "是"。

【第二步】等待自动安装 Node.js 和 Git

  脚本会自动检测你的电脑：
    - 如果没有 Node.js，会自动从官网下载 v20.11.0 LTS 版本并静默安装。
    - 如果没有 Git，会自动从国内镜像下载最新版 Git for Windows 并静默安装。
  整个过程约 3-8 分钟，请耐心等待，不要关闭窗口。

【第三步】等待 Claude Code 自动安装

  Node.js 和 Git 装好后，脚本会自动使用 npm 安装 Claude Code
  （使用国内镜像加速），安装过程约 1-2 分钟。

【第四步】粘贴 DeepSeek API Key

  脚本窗口会提示：
    "请输入你的 DeepSeek API Key，然后按回车"

  1. 打开浏览器，访问 https://platform.deepseek.com/api_keys
  2. 注册或登录 DeepSeek 账号
  3. 点击 "创建 API Key"，复制生成的一长串密钥
  4. 回到脚本窗口，右键粘贴（或 Ctrl+V），按回车

  （密钥只保存在你的电脑上，不会上传到任何地方。）

【第五步】看到"安装完成"后关闭窗口

  脚本会显示 "安装完成" 的提示信息。
  按任意键关闭命令行窗口即可。

【第六步】开始使用

  在任意文件夹（建议空文件夹）里右键 → 选择 "Git Bash Here"。
  在弹出的命令行窗口中输入：
    claude
  然后回车。第一次启动需要几十秒加载，之后就可以用中文对话，
  让它帮你写代码了。

  说明：因为脚本已经自动安装了 Git，所以右键菜单中一定会有
  "Git Bash Here" 选项。如果没有，请重启电脑再试。


【第二部分：一键清理（完全卸载）】

如果你想彻底移除本安装包添加的所有内容（包括 Node.js、Git、
Claude Code、环境变量、残留文件夹），请按以下步骤操作。

【第一步】以管理员身份运行清理脚本

  右键点击 "清理ClaudeCode.bat" → 选择 "以管理员身份运行"。

【第二步】按照脚本提示操作

  清理脚本会自动执行：
    1. 卸载 Claude Code（全局 npm 包）
    2. 删除 DeepSeek API 环境变量（ANTHROPIC_API_KEY 和 ANTHROPIC_BASE_URL）
    3. 打开控制面板的"卸载程序"窗口，请你手动卸载 Node.js 和 Git

  （手动卸载 Node.js 和 Git 是最安全的方式，不会影响其他软件。
   你只需在列表中分别右键点击它们，选择"卸载"即可。）

【第三步】删除残留文件夹（可选）

  卸载完成后，可以手动删除以下文件夹（如果还存在）：
    - C:\Program Files\nodejs
    - C:\Program Files\Git
    - C:\Users\你的用户名\AppData\Roaming\npm
    - C:\Users\你的用户名\AppData\Roaming\npm-cache
    - C:\Users\你的用户名\.npm
    - C:\Users\你的用户名\.gitconfig

【第四步】重启电脑

  建议重启电脑，确保所有环境变量变更生效。

至此，你的电脑已完全恢复到安装本工具包之前的状态。


============================================================
  使用小贴士
============================================================

◆ 新项目建议在空文件夹里启动 claude，能省 Token
  如果文件夹里文件很多，Claude Code 启动时会读取它们，这会消耗更多 Token。

◆ 一次会话里连续说多件事，不用每次重启
  每新增一个会话就要重新加载，消耗 Token。
  在同一个会话里，连续说你的需求就行。

◆ 输入 /clear 清空聊天历史
  聊久了觉得卡或上下文太乱时，输入 /clear 回车即可清空。
  不会额外扣费，相当于重新开始一个会话。

◆ 费用说明
  本安装包使用的是 DeepSeek 提供的兼容接口，
  费用按 DeepSeek 官方的 API 定价计算（远低于官方 Claude）。
  API Key 请妥善保管，不要分享给他人。


============================================================
  常见问题
============================================================

Q: 安装脚本运行后闪退或报错？
A: 请务必以管理员身份运行。如果仍然失败，请检查网络是否通畅，
   或暂时关闭杀毒软件再试。

Q: 安装后右键没有 "Git Bash Here"？
A: 重启电脑即可。如果还是没有，请手动安装 Git（官网 git-scm.com），
   安装时勾选 "Git Bash Here" 选项。

Q: 清理脚本打开控制面板后，找不到 Node.js 或 Git？
A: 说明它们可能已被卸载，或者不是通过本安装包安装的。你可以直接
   跳过手动卸载步骤，进入下一步删除残留文件夹。

Q: 如何确认安装成功？
A: 打开 Git Bash，输入 claude --version，如果显示版本号就成功了。
